# Olist E-Commerce Data Analysis

## Project Overview
This project analyzes the Brazilian Olist E-Commerce dataset to understand sales performance, customer behavior, product category performance, and delivery efficiency.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Project Objectives
- Analyze overall sales and revenue.
- Understand customer purchasing behavior.
- Identify repeat customers and customer segments.
- Analyze delivery performance.
- Identify top-performing product categories.
- Analyze payment methods and state-wise revenue.

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Customer Analysis
5. Sales and Product Analysis
6. Power BI Dashboard Development

## Dashboard Pages
- Sales Overview
- Customer & Delivery Analysis
- Business Insights

## Key Findings
- Analyzed approximately 96K unique customers.
- Identified approximately 3K repeat customers.
- Evaluated on-time and late deliveries.
- Analyzed revenue by product category, payment method, and customer state.
